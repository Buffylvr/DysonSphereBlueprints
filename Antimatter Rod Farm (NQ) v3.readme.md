# Antimatter Rod Farm (NQ) v3

Requires 145 GW of Dyson Sphere Power at 99% Ray Receiver Efficiency. 10 of these fit on a planet planet.

Inputs: Blue Proliferator, Deuterium, 14.7k Iron Ore, 1k Sulfur, 1k Titanium Ore, 4.3k Silicon Ore, 6.5k Copper Ore, 1.2k Fire Ice, Warpers.

Produces 900 Antimatter rods a minute and will power itself and max power draw once up and running. 

There is a fairly large overflow of critical photons (1800/minute) so the ILS that collects them is set to ship out. Use as you see fit.

There is also an ILS set to 0 for graviton lens and remote receive. Increase the number above zero if you want to bring in graviton lens to support the number being produced natively. The BP WILL fill the belt over time, but it will take about 18 hours to catch up from start if producing 100%. You can ship some in at the start to jump start all the ray receivers if you want and turn it off later. 

The belt cycling strange matter on the outside is decorative and serves no purpose.
