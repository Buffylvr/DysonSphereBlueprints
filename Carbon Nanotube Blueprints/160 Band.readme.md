# 160 Band

188 Quantum Chemical Plants: 14,100 nanotubes/min, 33,840 stalagmite/min, about 639 proliferator/min (451 for the stalagmite, 188 for spraying the nanotubes).

Band: 160-segment band, 29 to 47 deg. Fills the band's full height, 2 ILS (offset sideways, 29.6 m apart). In the northern hemisphere rotate 180 deg.

ILS: Spiniform Stalagmite local receive / remote provide, Proliferator Mk.III local + remote receive, Carbon Nanotube local + remote provide, Space Warper local + remote receive.

Quantum Chemical Plants in extra-products mode with Mk.III: 75 nanotubes/min and 180 stalagmite/min each. Nanotubes are sprayed with Mk.III by spray coaters before they enter each ILS.

Tesla towers included; no power generation.
