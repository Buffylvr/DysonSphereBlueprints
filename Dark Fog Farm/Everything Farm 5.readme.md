# Everything Farm 5

This is the 5th BP in the "Everything farm" series of blueprints. It requires the 300 facility blueprint technology and has belts that connect mid-air with the previous BP. If you're wondering why some drops from the previous BP aren't being sent to storage depots or PLS, it's because you haven't dropped this BP yet.

Like previous BPs in this series, it integrates with the previous ones and depends on them. As always, drops don't show up in the BAB filter and loot pool until you have researched them so if you aren't seeing a drop, check those two things first.
