# Everything Farm 1

This is the base level with holo beacons and nothing on top of the BAB.

This is the first in a series of 7 (currently) that builds out at the tech appropriate levels. This BP requires you to have unlocked the 150 facilities level of blueprints and depends on having unlocked several battle techs like holo beacons, signal towers, BABs, and lasers. There are 27 laser turrets in this BP, which is intended to be able to handle a level 30 planetary base without any energy weapon upgrades.

It also trims plasma sentries and only allows 3 of the 6 possible raider camps to spawn. As such, this BP only allows up to 432 DF units a minute, verses one with the six raider camps which allows up to 864 units a minute. This BP can be placed a total of 22 times on a planet for a total of 44 dark fog bases on a single planet.
