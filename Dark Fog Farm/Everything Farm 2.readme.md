# Everything Farm 2

This is the second in the "Everything Farm" series of BPs. It requires the 150 facilities limit BP to be unlocked but requires no additional technologies compared to the first BP in the series. 

You can use the Tesla towers as "anchor" points to properly drop this BP to the right of the first BAB from BP #1
