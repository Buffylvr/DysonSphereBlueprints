# Everything Farm 6

This is the 6th BP in the "Everything Farm" series of blueprints. While not the last BP, it is the last one that controls drops from the loot pool. This will handle through all the level 24 Dark Fog drops. One slight different from previous versions of this BP - it doesn't directly tie into the previous ones, but does use the signal towers and laser turrets as "anchors" to ensure the the BP lines up properly when you place it. 

It does also place a shield generator with each one.
