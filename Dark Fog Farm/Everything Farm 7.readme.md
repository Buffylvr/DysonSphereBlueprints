# Everything Farm 7

This is the seventh BP in the "Everything Farm" BP but it doesn't have to be the last one that gets placed.

If you place 22 of these BPs across the planet then with 100% wind and solar on the planet this BP will generate about 3.5GW - each BP generates roughly 320 MW, but if you have 22 on the planet only half have light at any point, so it's basically 160 MW x 22. 

22 of these BP will use about 1GW of power to operate all the Shield Generators, PLS, BAB, lasers, and bots/belts/sorters so it leaves you plenty of leftover power to do whatever you want at the poles. 

While this is the "last" in the series, it can be placed at any point - the only techs it requires are solar panels and wind turbines which unlock very early - it SHOULDN'T be placed until both DF based from the first BP have landed. If you place this before they land, then when they land they will destroy about 20 solar panels each. So wait until they land, then place this. The BP accounts for how the planetary base grows and the unit's won't attack these as they head for the signal towers first.
