# 【Ultimate Spinner】 82K Deuterium - 1/20 Sphere

Deuterium 1/20 Slice

Consumes 82K Hydrogen + 1.4K Proliferator per minute, producing 82K Deuterium — enough to fully cover one 32,000-"sugar" load (community slang, exact referent unclear). I honestly can't figure out why you'd need this much deuterium to fill the gap, but the blueprint's made, so might as well share it. If you're only laying down a single piece, you can pair it with a smaller Mini Artificial Star setup instead.
The production line is designed for minimal throughput loss where possible; recommended shipping capacity is Interstellar Logistics Vessels Level 30+, and try not to build too far from a gas giant.
