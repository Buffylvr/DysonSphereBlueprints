# [Ultimate Spinner] 82K Deuterium - 1/20 Sphere

Deuterium 1/20 Slice

Consumes 82K Hydrogen + 1.4K Proliferator per minute, producing 82K Deuterium — enough to fully cover a 32,000/min consumption need. Honestly I'm not sure why you'd need this much deuterium to fill the gap, but the blueprint's already made, so might as well share it. If you're only building one slice, you can pair it with a smaller Artificial Star setup instead.
The production line is designed for minimal performance loss where possible — recommended vessel engine level is 30+, and don't build too far from a gas giant.
