# 100% coverage clear

Uses only 28000 foundations to make a planet fully 100% buildable. Toggle "Foundations fill depressions only" to use even less foundations.

The basic building stone is horizontal bands with 3 tiles in between and 2 tiles between horizontal bands. Two adjacent horizontal bands are 2 offset, such that the foundations form triangles.

Care has been taken at fault lines to make this scheme work
